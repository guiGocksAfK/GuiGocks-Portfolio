# GuiGocks-Portfolio
# Guilherme Gabriel Gocks — Portfólio

Etapa 1: Hero responsivo. Next.js App Router, TypeScript, Tailwind CSS e Motion.

## Desenvolvimento

```sh
npm install
npm run dev
```

## Verificação

```sh
npm run lint
npm run build
```

Conteúdo e links: `src/data/content.ts`. Cores e estilos: `src/app/globals.css`.
Fontes Geist e Geist Mono servidas localmente pelo Next.js após o build.

Projetos e Sobre aparecem como rótulos inativos na navegação durante esta etapa.
Contato leva aos links do Hero. Nenhuma outra seção foi implementada.

Deploy: importar o repositório na Vercel, usando o preset Next.js. Sem variáveis de ambiente ou backend.
